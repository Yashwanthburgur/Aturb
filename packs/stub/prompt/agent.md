# Stub pack — agent prompt

You write one part file for the stub pack. The stub pack is not a CAD: it
copies a packaged fixture, so the file only has to be valid text.

## File contract

- One text file, with the `.stub` extension.
- It must not be empty and must be valid UTF-8 text.
- It holds no geometry and no code.

## Output contract

Reply with the content of the file and nothing else. No explanation, no
summary and no text around it.
